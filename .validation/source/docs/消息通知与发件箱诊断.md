# 审核通知与消息发件箱诊断

## 范围

本次修复覆盖小程序管理员审核师傅后的 PHP 本地身份投影、站内审核结果、微信订阅消息发件箱、审核列表状态回显，以及后台消息发件箱的逐次诊断。云端师傅审核状态仍是事实源；本地通知失败不得反向回滚已经完成的云端审核。

不新增数据库表或字段，不修改现有 `message_outbox.business_key` 的 128 字符约束。

## 师傅身份投影

- 只使用云数据库记录原始 `_openid`，并校验本小程序真实 OpenID 格式 `oyAoh...`。
- `serializeAdminWorker` 返回的 `openid` 是展示别名；云端 `ownerKey()` 在原始 `_openid` 缺失时会回退为记录 `_id`。禁止把该别名或 `_id` 当成微信身份。
- `admin.review` 返回缺少原始身份时，先按当前小程序 AppID 查询已有本地身份映射，再使用准确云端记录 ID 调用 `admin.list` 补查；不扫描全量师傅。
- AppID、原始 OpenID 或本地身份仍不可用时，不创建伪微信身份，也不向伪 OpenID 发消息。审核结果照常返回，通知状态记为未发送。

## 审核通知状态

| 状态 | 含义 | 是否会自动发送 |
| --- | --- | --- |
| `pending` | 等待发件箱调度 | 是 |
| `processing` | 正在调用渠道 | 当前任务执行中 |
| `failed` 且有下次时间 | 暂时失败，等待重试 | 是 |
| `failed` 且无下次时间 | 已停止重试 | 否 |
| `processed` | 渠道接口已受理，不代表最终送达 | 否 |
| `closed` | 管理员已结案 | 否 |
| `skipped` | 未满足订阅/身份条件或通知入队异常，未调用微信接口 | 否 |

通知未入队时仍保留站内审核结果，并在通知数据中记录未发送原因；同时写入终态 `skipped` 发件箱记录。缺少本地师傅映射时也保留可供管理员查询的跳过记录，但不伪造接收账号。

审核列表先展示云端审核结果，再按当前页准确云端 ID 补查 PHP 发件箱状态。查询暂时失败会显示独立的查询失败状态，并在用户刷新时重新查询；不会覆盖云端审核结果，也不会将另一位师傅的通知误匹配过来。

## 幂等键与状态对账

- 审核通知幂等键仍使用 `worker-review:` 前缀，完整长度不超过 128 字节。
- 云端 ID 超出可用长度时，对 ID 部分使用 SHA-256 摘要缩短；原始完整云端 ID、审核状态和审核记录 ID 保存在 outbox payload。
- 状态对账优先使用本次云端审核时间定位本地 `worker_verifications` 记录，再按 payload 中的完整云端 ID、审核状态、`review_id` 和 `review_time` 精确匹配；旧记录才使用有时间边界的兼容查询。
- 本地师傅映射缺失时，幂等键使用云端审核时间摘要区分连续审核事件，不再让所有事件共用 `review-0`；重复写入同一 `skipped` 事件会刷新记录时间。
- `skipped` 不进入 dispatcher 的待发送查询，不消耗订阅次数，不触发短信兜底。

## 发送历史与安全诊断

每条发件箱 payload 最多保留最近 20 次尝试：

- `accepted`：渠道接口已受理；
- `failed`：本次调用失败，并保存错误摘要；
- `unknown`：发送进程超时回收，实际送达结果未知；进入终态并停止自动重试，避免供应商可能已受理时重复发送。后台列表显示“结果未知”，审核列表使用独立状态，不提供直接人工重试。

微信订阅发送成功后，供应商受理回执与本地订阅次数在同一数据库事务中确认。若该事务失败，系统会单独保存受理回执并记录本地额度同步警告，保持消息为已受理，不重新发送。若受理回执也无法保存，则记录 `delivery_outcome=unknown` 并停止自动重试，等待管理员核对渠道结果。

微信明确返回 43101 时，即使本地订阅额度归零失败，也会继续将当前消息标记为终态失败；不会因额度同步异常让消息停留在 `processing`。

后台“消息发件箱”默认只显示简短错误摘要。展开“查看完整诊断”后可查看业务编号、接收对象、创建/完成/下次重试时间、渠道回执和逐次尝试历史。历史记录不会展示原始消息正文；诊断输出会脱敏手机号、真实 OpenID、访问凭据和企业微信 Webhook 密钥。

PHP `ParseError` 属于代码/部署缺陷，不会通过重复调用自行恢复：立即停止自动重试，保留文件、行号和请求编号，不消耗订阅额度，也不触发短信兜底。其他微信临时错误继续沿用 1/2/4/8 分钟退避，第 5 次终止；已有明确不可重试错误码仍按原策略处理。
