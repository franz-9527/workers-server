账号授权、实际API Name、免费资源包/期限和合法取件能力是联调配置项，不再重新讨论选型。access_token/AppSecret仅在可信后端保存，复用项目凭证管理；不下发给小程序，不把整条私有URL写普通日志。不得因识别失败自动切换另一供应商。


### WechatSI 同声传译插件的兜底边界

同声传译插件可以作为**客户端辅助识别兜底**，但不能替代服务端可信ASR作为自动放行依据。插件通过小程序端 `WechatSI.getRecordRecognitionManager()` 在录音过程中识别，最长60秒，并在停止时返回临时音频文件和最终文字；它不能在Go/PHP服务器收到既有MP3后再补跑。接入还要求当前小程序先在微信公众平台取得该插件使用权限，并在app.json声明provider；仓库不能仅靠代码判断账号是否已获权。

2026-11-08 起语音消息继续保持“先发布语音、后台识别”的非阻塞链路，但识别优先级调整为：**腾讯云 SentenceRecognition 成功结果 > 客户端插件临时结果 > 纯语音**。WechatSI（wx069ba97219f66d99，0.3.10）仍可在录音阶段产生 client_transcript，让发送端即时看到文字；音频上传和本地预处理完成后直接发布，不等待云端识别。后台腾讯云识别成功后会把 chat_av_uploads.transcript 更新为可信服务端结果，下一次消息增量/刷新读取即展示服务端文字；若腾讯云失败则保留客户端备用文字，没有任何文字也保留纯语音。识别故障不改变已发送语音状态。客户端插件文字属于辅助展示，不作为硬性放行/拒绝证据；服务端可信 ASR 结果可继续进入既有文字安全规则。

## 3. 自动识别、存储与交付流程

用户按住录音→客户端生成≤60秒单声道压缩音频→申请订单绑定上传意图→七牛私有隔离对象确认→worker校验编码/时长→服务端调用一句话识别→MySQL保存官方原结果/RequestId→文字内容安全及号码/微信号/私单规则→必要可信原媒体检查→最终事务复核订单仍可发送→发布语音及文字。

默认录制/交付格式建议16k单声道MP3，目标24–64kbps、最终≤1MB；[官方录音参数](https://developers.weixin.qq.com/miniprogram/dev/api/media/recorder/RecorderManager.start.html)当前列16k对应24–96kbps，起点可选48kbps，仍需真机核验实际编码；优先一次编码后直传，避免先AAC后MP3常态转码。兼容旧音频/不支持格式时，仅有界worker转换；最终交付/识别输入尽量使用同一MP3对象版本，不能识别一份、发布另一份。

七牛按第12章默认永久保存正式音频交付件，MySQL按相同策略保存识别文字、音频引用、时长、来源service_market_server、service/api/engine、UsrAudioKey、供应商RequestId、配置/规范化规则版本和审核状态；“服务端保存”遵循第12章分类型后台策略；客户端按微信实际容量缓存并由用户清理，宝塔不保留永久音频档案。

图片无损优先优化沿用现有服务；音频压缩是有损编码，不混称无损。临时转换源文件/中间件按TTL清理，不额外保存通话录音；未发送草稿不进入正式管理员聊天记录。

已确认发送的语音消息保存原识别结果，展示/播放不重复调用。纯“语音输入转文字”另列EXT01可选子项，不默认上传未发送草稿或保存修改历史；若启用须明确用户动作、本人私有短期任务和TTL、取消/删除规则，不进入管理员正式聊天记录、不自动发送原音频。用户最终发送的文字仍单独审核；不将其隐式扩展为云草稿。

## 4. 自动任务可靠性与风控

任务幂等键为音频对象版本/hash+service+api+engine+语言/处理配置版本+授权用途；不能信客户端提交识别文字/通过状态。UsrAudioKey/client_msg_id作追踪，不默认等于供应商对重试提供完全免费幂等。

初期外部识别并发2，短任务排队与指数退避，远低于25次/秒上限；token/参数/授权错误不盲重试。超时可能已消耗额度，按接口实际查询/重试语义处理；未核实支持异步识别/结果回查时，不编造job查询接口或直接开async=true。

失败/配额耗尽/空结果/低可信语音不直接放行，仅发送方显示检测中或失败、重试/改文字入口；不向接收方生成待审占位。服务故障不记违规；语音识别属于增强能力：SentenceASR 失败后优先使用同声传译文字，无文字则直接保留纯语音；识别失败、额度不足或识别结果未知不再进入发送前 raw media gate，也不增加管理员预审。其他未知错误、额度错误或无法确认是否已调用的结果仍不得进入该通道。正常可信ASR继续自动走文字安全规则；已授权管理员仍能在发布后按既有权限抽检压缩音频。

原音频已由服务器选定，文字是可信供应商响应，但机器仍会识错/漏号码。噪声、主要方言、拆音节、英文数字/金额施工负例纳入样本；明确风险、投诉和用户申诉按需人工复核，普通无风险会话由管理员自由抽检，不要求固定每日比例或逐条听审。不能把ASR成功等同完整内容安全或100%阻止私单。

FilterDirty等供应商过滤参数建议保留未过滤识别结果供审核，另建展示/规范化文字，避免脏词/风险内容先被过滤掉；具体参数按选定接口支持验证。图像按[风控第13章](风控、管理员审计与语音识别.md)用本机二维码/可选OCR及人工模式；视频仍按独立门禁，视频音轨仅在服务契约允许时有界转成≤60秒输入复用识别，否则不开放该类视频发送并提示改文字/图片；不顺带开放长文件服务。

成功发布前再次校验episode/成员/关闭/冻结。识别在关单后返回可保留必要任务审计但不发布新语音；同一媒体重新受理售后也不能绕过原幂等/成员权限。管理员修改转写只追加纠错，不覆盖官方原结果或音频。

## 5. 后台文字优先、音频可播放

后台聊天流语音行默认显示识别文字、发送人/订单/阶段/时间、识别及风险状态；音频播放按钮/时长放在次级位置，不自动播放。展开可看原识别与纠错、服务RequestId、对象版本和复核结论，普通列表不展示长期下载token。

有权限管理员点播放时按消息/风险权限签七牛HTTPS短效URL，浏览器直接播放；不让PHP把整段音频读入内存代理。待审/被拦件仅风险复核角色可播放；后台查看/播放/导出留访问审计，不产生普通用户已读/已听回执。

未完成识别在本人发送端显示“识别中”，失败显示原因、重试/改文字，明确风险可申请复核；后台仅风险区按授权查看未发布证据，不把空文本当安全通过；机器文字标注可能有误。后台首期按会话/时间/类型筛选并分页查看文字，P1关键词检索须有索引/查询预算，禁止全库正文LIKE扫描；私单复核必要时听交付音频，不能只凭转写自动罚款/判责。

一个通道不足选另一可用通道；两池耗尽停止新呼叫，活动call仅兑现已预占段，到安全边界结束，不付费续通、不扣钱包、不买包。两池都不可核验或故障时用“服务暂不可用”，不得显示假耗尽或把未知数据归零。恢复周期以供应商真实权益确认为准，不因本地跨月自动创建赠送额。

## 9. 不录音录像与运营审查

前期不保存实时通话录音/录像，也不做通话ASR；后台只看参与者、订单、类型、通道、状态、计量来源与资源消耗。管理员可按人员审计，不按人员设置限额，不生成充值、收费或收益报表。

呼叫/接听前提示留在平台沟通、禁止交换私人联系方式/站外交易，并提供举报；实时通话口述号码与画面二维码没有本期自动拦截能力，不承诺全内容监控。原聊天消息的安全检测和证据权限继续执行，通话不会自动改变订单价格、验收、退款或售后责任事实。

## 10. 联调与放行

消息ASR/原音检测的既有契约保持：核验授权/API Name、短效取件/格式/回调，100～200条合法工地样本及噪声/拆号风险验证；不把通话资源池规则套给语音消息。

## 11. Go与PHP实施归属

Go写呼叫信令/attempt/双端忙线及界面记录；PHP CallQuota写平台共享周期池、预占/计量/对账及追加纠正，使用同call_id/attempt/window关联。Go只调用受保护资源用例，超时查原操作，不直接改池、建立个人额度或操作钱包。

两端不共同写一张call状态表，也不持Go聊天事务锁同步等待PHP；MySQL是真源、Redis仅辅助。凭证可持续媒体的有效期与可验证强停延迟必须被预占覆盖。详细锁序、单位、R/L/官方用量覆盖、原始证据与恢复边界以资源附录为准。

本次仅更新设计，未实现或开启通话，不自动开外部服务/采购/部署。EXT03双通道、EXT04共享资源、EXT05后台/免费停用、EXT06联合验收按清单独立推进。

## 12. 语音/视频消息成本与留存开发契约（2026-10-24）

2026-10-25补充：60天仅为七牛视频原文件期限。消息记录、当前获权的本机副本、视频封面及最多8张抽帧继续保留；所有类型的有效本机缓存不按年龄删除。覆盖旧封面随视频到期、到期清本机的描述。

### 12.1 录制和相册

相机30秒、压缩交付≤8MiB；相册120秒、选中输入及交付各≤20MiB。MiB=1024×1024字节，边界等值允许，超过显示当前及超出MB。客户端wx.compressVideo设置bitrate=1000、fps=24、按原比例分辨率缩放到短边≤720/长边≤1280，不放大；服务端基线H.264/AAC MP4，接口没有指定H.265编码器。格式不兼容不能假报检查通过。

语音1～60秒、单声道16k MP3/48kbps/≤1MiB；录音松开后可试听并明确发送，上滑取消；权限返回太晚、页面隐藏、通话占麦不能自动开始或发送。≤60秒约360KB是编码估算，不是硬保证。

### 12.2 云保存与后台

文字正文、图片及缩略图、语音原件默认永久，视频原件默认60天。PHP原后台按类型配置永久或1～3650天、仅新消息或预览后的历史范围，绑定版本、管理员、CSRF及审计；Go应用并记录进度/缺失对象。转永久不能恢复已被删除的云文件。

视频封面及最多8张480px以内、≤64KiB的抽帧不跟原片删除。已发布消息及稳定hash引用保留，本机副本仍能读；本机无原片时提示云文件已清理。未发布、失败、取消和证据仍有独立TTL，不永久收集全部尝试。

### 12.3 直传、检测与成本

视频大于4MiB使用2MiB精确片，20MiB最多10片；Wi-Fi并发2、其余1。片凭证绑定key和准确字节，先Stat确认，worker合并核对MD5和真实格式后生成不可覆盖的SHA256交付件。恢复只补缺片，已签片取消后仍占滚动预算。默认每账号24小时20条/100MiB，后台可调；不做HLS或多档长期副本，不占FPM传输媒体。

固定既定服务市场wxa8386175898e12c9与SentenceRecognitionWX。外层API Name及data编码在绑定账号实测，不能用Action猜填api；相册长音轨分两段≤60秒，不把120秒直接送一句话接口。先落调用状态及预算，响应未知不盲重复付费。语音原件还需微信media_check_async真实结论；视频完整画面和声音需独立人工预审，抽帧仅辅助。

临时源part/check对象短期清理；正式对象取消临时TTL，应用worker按正式发布时间清云原件。不要给永久图片/语音或视频保留图片配置通用60天桶规则。[七牛生命周期](https://developer.qiniu.com/kodo/8609/dev-life-cycle-management)按上传日界且新规则不自动处理旧对象，不能冒充精确应用删除结果。

### 12.4 低频后台，默认关闭

总开关默认false，可设置媒体类型、对象年龄、闲置天数、最小大小、有限期剩余天数和批次。默认年龄60天、闲置30天、≥64KiB、有限期剩余≥32天；默认60天视频不转低频。开启前管理员预览并确认费用；关闭停止新迁移，不自动把已有低频全部转标准，不购买智能分层。

[七牛低频](https://developer.qiniu.com/kodo/3956/kodo-category)有64KiB最低计费、30天最低保存和取回费用；默认不调用转低频接口。永久保存仍可能持续增长，用户明确需要时再调整云保存策略。

### 12.5 本机缓存与播放

[微信setStorageSync](https://developers.weixin.qq.com/miniprogram/dev/api/storage/wx.setStorageSync.html)为总10MiB、单键1MiB的键值缓存，不是文件系统统一上限。[官方接口类型](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)亦不能把downloadFile单次上限当总文件额度。正文和媒体用文件系统，不设额外64MiB、消息数、会话数或年龄上限，不日常LRU。

按已查看正文和主动打开/播放的媒体缓存，不全量下载云历史。按当前身份/会话授权返回hash及cloud_available；云文件已清理但本机同hash存在时直接播放，不请求CDN。视频封面/抽帧逐张按需查看。原视频已删除、本机又被用户清除时明确不可重新下载。

用户按类型/会话清理，文字默认不选，不改云记录或已读/已听；系统写满则提示并保留已有内容。隐藏停播/下载；撤回、屏蔽、失权、退出/换号仍清对应敏感内容。云端到期不删本机副本。管理员抽检不写用户已读/已听；普通语音仅实际播放结束声明已听。

### 12.6 启用验收

实际ASR授权/API Name/回调安全模式、两真机录音和120秒相册、云删除与设备缓存继续播放、抽帧保留、低频off和真实私有CDN分别验收。audio/video能力凭证和客户端入口保持默认关闭；具体代码与测试状态仅看[清单19](开发拆分与验收清单.md#19-当前进度与下一轮交接唯一进度入口)。不执行实时通话/计费开发，不替用户开通或购买外部服务。

## 13. 测试站网站 HTTPS 临时音频源（2026-11-07）

为隔离七牛下载域名、私有签名、CDN 防盗链或服务商出口可达性问题，测试环境的 SentenceASR 改为先从七牛读取**已经完成服务端转码的 MP3**，再复制到本站 `/uploads/chat-asr/`，最后把 `https://测试站/uploads/chat-asr/<64位随机名>.mp3` 作为 `SourceType=0` 的 URL 交给服务市场。正式 ASR 请求保持 `SentenceASR + data object + Url urlencode`，不再为了失败切换 JSON string。

该目录不是用户上传入口：仅 Go/PHP 后台从已核验聊天音频写入 `.mp3`；文件名使用 256 位随机值；Nginx 只允许符合随机名规则的 MP3 静态读取，目录内其他扩展名全部 404；文件默认 10 分钟后清理。测试站部署时受控探针也会把最近一次 9301002/9301003 的同一份 MP3 镜像到本站 HTTPS，再用 object 形态执行一次探测，因此可以直接比较七牛 URL 与网站 URL 的结果。

如果网站 HTTPS 源成功而七牛源持续 9301002/9301003，可把根因收敛到“服务商拉取七牛 URL/CDN/签名链路”；如果网站 HTTPS 源仍返回相同错误，则应优先继续排查服务绑定、供应商后端和商品配置，而不是继续改变 data 序列化。


## 14. 后台 ASR 自诊断（2026-11-07）

聊天设置中的 ASR 区域新增“ASR 自诊断”，只汇总已经存在的配置、Go 版本、WechatSI 插件探测、最近语音发送、后台 SentenceASR 结果和受控 Open API 探针；**刷新页面不会再次调用 SentenceASR，也不会增加识别调用次数**。

自诊断把证据拆为：小程序身份、WechatSI 插件、SentenceASR 契约、Go 运行版本、音频取件源、微信服务市场入口、供应商 RequestId、语音发布链路、服务绑定/商品后端。服务市场当前公开 Open API 不能直接枚举“某 AppID 是否已绑定某服务订单”的最终事实，因此后台不会伪造“已绑定/未绑定”，只在已有排除证据充分时给出“高疑：服务绑定 / 供应商后端”的归因。

当前测试站的高疑条件是：本站 HTTPS MP3 预检完成、正式请求固定 `wxa8386175898e12c9 / SentenceASR / data object / URL 编码`、微信 Open API HTTP 200、返回 `9301002/9301003`，且供应商没有 RequestId。在该组合下，后台自动把七牛/CDN 降为低疑，并提示管理员核对当前小程序 AppID 对应的服务市场订单、授权期限/套餐和供应商后台状态；同时给出 intent、source host、HTTP、errcode 和 RequestId 是否存在，便于直接提交微信/服务商工单。


## 15. 腾讯云一句话识别直连主方案（2026-11-08）

语音消息服务端识别从微信服务市场 `SentenceASR` 切换为腾讯云 ASR 云 API `SentenceRecognition`。主方案由 Go 服务直接调用 `asr.tencentcloudapi.com`，使用 TC3-HMAC-SHA256；后台保存 SecretId / SecretKey 密文，运行时仅通过私有环境变量注入 Go，不把长期密钥下发到小程序。

施工语音默认使用 `16k_zh_dialect` 多方言引擎；后台可切换 `16k_zh` 普通话、`16k_zh-PY` 中英粤混合、`16k_yue` 粤语。音频继续沿用既有服务端 MP3 处理与 HTTPS 取件链路，`SourceType=0`，不再经过微信服务市场 `wxa8386175898e12c9 / SentenceASR`。历史服务市场探针保留代码用于旧证据读取，但新 profile 下诊断脚本不再发起该外部调用。

小程序实时插件 `QCloudAIVoice / wx3e17776051baf153` 不进入当前生产链路：历史公开示例直接向插件设置腾讯云长期 SecretId / SecretKey，不符合本项目密钥边界。若后续确实需要“边说边出字”，单独实现短期临时凭证后再启用。现有 `WechatSI / wx069ba97219f66d99` 更新到 0.3.10 并保留为客户端备用；它的转写失败不阻塞纯语音发送。

后台“本月本站一句话识别”统计来自 `chat_av_asr_requests` 中 `service=tencent_cloud_asr` 的真实落库结果。免费额度剩余只按官方每月 5000 次**成功调用**做本站估算；腾讯云当前公开 `GetUsageByDate` 文档没有列出一句话识别独立 BizName，因此不把本地估算冒充官方资源包余额。官方资源包总量、余量和预警仍以腾讯云语音识别控制台为准。
