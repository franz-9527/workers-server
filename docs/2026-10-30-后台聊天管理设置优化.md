# 2026-10-30 后台聊天管理设置优化

适用分支：chat、main。开发目录：壁选师傅开发版。验证只在 workers-server 独立测试仓库执行。

## 页面与预设

- 通话管理新增「通道密钥」分页；登记、功能设置、存储与保存期及授权表单采用响应式多列布局。
- 登记默认选择实际使用的声网小程序 SDK，带入已保存的 App ID、当前自然月及起止日期、最近一次声网资源的真实共享范围。新账号的共享范围、实际免费权益、官方已用量仍需核对账单填写。
- 声网现行标准时长规则：小程序语音系数 143/100、高清视频 429/100；登记的秒级计量为平台保守估算。不能把其他端的 1/4 系数或历史套餐直接套入小程序。
- 变更供应商会清空上一通道的计量与额度字段，同时取消核验勾选。已输入内容按通道临时保留，避免误用；所有真实核验、免费边界和启用开关均不自动勾选。
- 声网免费权益按账号共享；免费时长是否存在取决于账号及套餐情况，页面不替账号断言免费额度。自然月日期可按真实合同修改。微信费率不在无法核实官方规则时猜填。

## 密钥与服务接入

后台加密保存声网 App Certificate、REST 客户 ID、REST 客户密钥，App ID 可见。密码框不回显，留空保留原值；更换 App ID 必须填齐凭据。清除后台凭据会停用该通道，不恢复旧环境变量凭据。

仅超级管理员可保存，仍有 CSRF、权限、设置版本和事务锁。存在活动／待确认通话、预占或待对账用量时，禁止变更密钥，防止遗留通话失去停用权限。管理记录仅存字段名和操作类型，不保存密钥原文。

Go 通话服务通过已有 HMAC、环境隔离、时戳、随机数防重放的内部 HTTPS 接口读取后台密钥，每次相关操作重新读取；接口失败时停止声网准入，不回退旧密钥。原环境变量配置在首次后台保存前保留兼容。前端只获得短期通话令牌，不获得供应商证书或 REST 密钥。微信通道继续复用既有后台微信配置。基础设施内部签名密钥仍由服务器环境提供。

## “修改理由”的用途

日常功能设置、确认提醒、登记资源、更新密钥、新消息保存规则、群人数上限取消强制理由；可选备注留空时自动记录操作名称。额度预算调整、官方用量导入、权益复核、人工确认停流保留「变更／核验说明」，用于追溯资金与核验依据。存储策略应用历史内容仍要求填写清理依据，并保留预览确认。聊天抽检授权、禁聊、案件处理和原始证据查看保留必要理由，并明确解释用途。

## 更新范围

需要更新 PHP 后台文件和管理端静态资源，并重新构建、更新 Go 聊天服务，建议先更新 PHP 再更新 Go；仅更新后台页面不能使旧 Go 进程读取后台密钥。不涉及小程序包更新。

不新增数据库表或字段，不需要结构升级。首次保存时在既有 system_settings 写入 chat_private 分组的加密配置；沿用既有 chat_call_admin_audit 记录。不改历史资源、历史额度与用户数据。部署前确认服务器隐私字段加密配置可用并保留解密密钥备份。
