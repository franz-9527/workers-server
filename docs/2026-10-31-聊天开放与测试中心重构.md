# 聊天开放与测试中心重构

本次修改同步到 `chat`、`main`。以本地开发版目录为编辑基准，仅在 `workers-server` 独立测试仓库执行验证。

## 聊天开关

- 后台路径：**聊天管理 → 聊天设置**。超级管理员可以开放或暂停，使用设置管理权限访问，保存操作校验 CSRF 并记入管理员审计。
- 取消小程序 `ChatRuntime` 中固定关闭的发布限制；开放状态通过 `chat.availability` 获取。进入消息页、返回前台立即同步，停留前台每 30 秒同步。环境变化时废弃旧请求，状态变化清理连接、消息及身份缓存；状态未变时保留当前会话。
- 新设置 `system_settings.chat.enabled` 默认开放。暂停会阻止 PHP 新凭证和 Go 已有小程序凭证的继续使用；Go 发送事务再次读取开关，后台审计权限独立保留。
- 不再使用旧 `config.chat.enabled` 发布常量。签名、聊天服务、订单权限同步、内容检查、恢复核验及音视频配置仍是独立的基础设施条件，不通过总开关绕过。

## 测试中心管理

- 首页拆为实例管理、创建场景、覆盖报告、环境诊断，按实际选中的页签渲染。
- 实例页拆为实例概览、订单流程、测量与代下单、售后与资金、消息与聊天、检查与记录、测试入口与清理。
- 消息与聊天继续分为模拟会话、通知收件箱、渠道与回执、聊天回归；检查与记录按数据检查、执行记录、订单事件、执行覆盖、失败复现、计划任务分别管理。
- 实例列表、检查、执行记录、订单事件和通知收件箱每页 20 条。实例支持搜索、场景及状态筛选；修复原搜索重复使用 PDO 命名参数的问题。
- 操作完成返回原功能页签；手机页签横向滚动，模拟聊天按角色区分气泡，长文字自动换行，输入区随屏幕宽度调整。

## 模拟会话

1. 在 testing 环境中创建测试实例，进入 **消息与聊天 → 模拟会话**。
2. 选择实例内的测试师傅，切换测试客户或测试师傅身份发送文字。
3. 在 **测试入口与清理** 生成对应客户或师傅的短期入口，在小程序兑换后打开消息页，即可查看和回复同一段会话。
4. 后台每次展示最新 50 条，可查看更早消息。小程序复用现有消息列表和对话页，支持文字、历史分页、未读、显式已读、撤回、置顶和稍后处理。

模拟数据存放在 `chat_test_conversations`、`chat_test_messages`，不写正式聊天、通知、短信、订阅消息、企微、资金或供应商队列；不签发 Go 登录凭证，不连接真实聊天 WebSocket。图片、音视频及引用回复不包含在本次模拟范围内，界面隐藏相关操作。

每个请求重新校验 testing 环境、有效登录与短期身份、实例状态、订单归属、当前测试参与者；禁止跨实例或跨师傅读取。已过期、已清理、归档、正式环境及审核展示样例均不能操作。清理与模拟收发共用实例锁，成功清理后删除对应模拟消息和会话。

## 发布及数据库

**涉及 PHP 后台更新、Go 聊天服务更新、小程序重新发布和数据库升级。**

- 服务版本升级至 `2.7.1`，通过既有升级器执行新增的 `server/database/upgrades/2.7.1.sql`。不修改已经发布的 2.6.0、2.7.0 迁移脚本及其校验值。
- 新增两张测试模拟表，并以 `INSERT IGNORE` 添加聊天总开关。重复执行不覆盖管理员已保存的开关，不修改订单、资金及既有聊天记录。
- Go 聊天服务的数据库账号需有 `system_settings` 表的 SELECT 权限，以读取开关；重新编译部署本次 Go 代码。保留原配置要求及发布/恢复核验，不向 Go 提供 PHP 私钥。
- 正式站开关与测试站开关分别保存在各自数据库；模拟功能仍只允许 `app.env=testing`。旧的签名回归夹具导出/结果登记功能保留在“聊天回归”页签。
- 本次代码提交不等于已更新线上站点；上线后应在后台核对开关，并完成小程序真机与正式聊天服务连通验证。

## 验证

独立测试仓库执行真实 MySQL 5.7 模拟会话与权限边界验证、PHP/Go 凭证校验、现有 ChatManager 回归、原生响应到前端模型联调、WXML 编译，以及实际 PHP 模板的桌面/手机明暗布局检查。测试工件仅上传截图和渲染页面，排除凭据响应数据。
