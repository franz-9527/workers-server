# 微信订阅 47003 与施工进度模板（2026-11-01）

管理员提供的施工进度模板包含订单号、备注、更新时间、订单状态、项目名称。旧格式器允许 phrase 16 字、character_string 64 位、中文姓名 32 字，超过[微信官方订阅消息限制](https://developers.weixin.qq.com/miniprogram/dev/server/API/mp-message-management/subscribe-message/api_sendmessage.html)。47003 表示模板数据/关键词格式错误，不能当成授权次数不足。历史错误只保存代码，无法倒推该条记录的具体错误字段；不伪造已定位的字段或实际送达结果。

修复：
- thing 最多20字；phrase 仅汉字、最多5字；编号字符串最多32位；中文或中英混合姓名最多10字、英文20字；车牌最多8字。补充时间、日期及数字的基本有效性检查。
- 业务“当前状态”映射到 phrase 时，超过5字或含逗号、数字的长状态显示“进度更新”；简短合法状态保留。具体事项保留在 thing 备注（最多20字），不把状态截成半句话。测试与业务投影使用同一方法。
- 微信发送网关对管理员测试与排队消息统一整理字段，发送前检查结构、空值、可转换类型；带场景时核对当前模板 ID 和已同步字段。不会把缺字段请求发给供应商。
- 47003 记录增加安全诊断：微信明确返回字段时展示中文名称、字段编号、类型规则，以及可用的 rid 请求编号；不保存/回显原始 errmsg 中的手机号、OpenID、Token 或字段正文。未给出字段时明确提示同步模板、核对映射和固定值。
- 发送错误统一使用“微信订阅消息发送失败（代码）”，恢复现有队列的不可重试错误识别。47003 停止重复重试，且不归零授权额度；43101 才同步失效订阅权限。管理员失败测试不自动重发，也不扣减可用次数。
- 模板选择项和高级字段旁增加简短类型限制，沿用现有布局，不新增模板或改写已保存的绑定。

本次需要更新 PHP 后台及视图；无需更新小程序、云函数、Go 或数据库结构。原模板可继续使用，不需要重新申请模板或让用户批量重授权。部署后先在消息配置同步实际模板，再选择管理员进行一次真实测试核对。本次仅在独立测试仓库模拟微信响应，不读取真实凭据、不发送真实消息。历史失败记录保留，不自动补发。
