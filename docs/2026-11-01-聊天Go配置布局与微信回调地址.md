## 这个地址配置在哪里

是小程序后台“开发 → 开发管理 → 消息推送配置”的 URL 服务器地址，用于接收媒体异步审核事件。实际地址取当前站点的 APP_URL，加 `/chat/api/v1/av/callback`。测试站和正式站分别显示各自地址，不从浏览器 host 猜测地址。

[微信消息推送官方说明](https://developers.weixin.qq.com/miniprogram/dev/framework/server-ability/message-push.html)要求配置服务器地址、Token、EncodingAESKey 和消息加解密方式。当前 Go 媒体回调验证加密签名和 AppID，并接收 wxa_media_check 事件；支持 JSON/XML，使用安全模式。界面只提供已有入口信息，不自动修改微信后台配置。

先保存本站 Token/EncodingAESKey 并应用 Go 配置，使验证入口就绪；再到微信后台提交验证。验证成功后勾选确认、再次保存并应用配置。更换 AppID、域名或密钥后重新验证。此入口仅用于媒体审核；若微信已有业务消息入口，按既有部署文档保留原入口，并将媒体审核事件按用途分流，避免覆盖其他业务回调。
