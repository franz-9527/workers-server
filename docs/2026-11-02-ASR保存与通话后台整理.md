# 2026-11-02 ASR保存与音视频通话后台整理

## 保存与回显

- 语音识别提供“微信一句话识别（SentenceASR，预设）”、自定义、暂不使用三种选项。原有自定义API及数据编码保持兼容，正常使用预设无需填写API名称；服务市场授权仍由实际小程序账号完成。当前数据编码默认沿用对象形式，JSON字符串作为高级选项保留。预设不代表外部服务授权或真实识别验收通过。
- 已保存的工具路径、ASR服务、接口名称及编码独立读取，不依赖七牛、回调、资源池等能力诊断成功。部分字段未提交时保留原值；自定义接口空值明确报错；停用使用显式选项。
- 保存失败保留当前表单输入；回调校验失败时事务回滚，不覆盖先前ASR配置。
- 资源登记及复核的允许使用、权益确认、实际停止能力三项均回显已保存值；返回登记页恢复本期资源的勾选和用量有效时间。
- 官方已用量未知时，权益确认意图保存在现有meter_json的entitlement_confirmed字段，实际verified仍为false，防止未知用量被当作零。页面说明确认已保存及尚待补充事项；录入官方用量后需保存复核，不能通过保留勾选直接绕过准入。
- 测试站不再将已关闭的通话、语音、视频开关强制改为开启；保存及刷新尊重实际选择。

## 页面与应用

音视频通话分为“功能与密钥、资源与用量、活动通话、通话记录、管理记录”。功能开关、优先通道和声网密钥使用同一表单、同一事务保存；旧credentials入口兼容到功能与密钥。资源登记作为资源页的子操作，不再占用独立顶级分页。

检测配置、空频道停止接口自检及应用配置按钮只在功能与密钥页显示。资源页保留单个跳转入口，不重复整套模块。

配置或资源变更成功后，测试站向现有启动器提交固定的重新应用请求，不在网页执行命令。状态目录不可写或应用请求失败时明确区分“已保存”和“尚未应用”，不把保存成功伪装成事务失败。正式站仍走独立发布流程。

密钥仍按既有要求在授权超级管理员表单中明文显示，数据库加密保存。未变化的明文回填不会重复加密或被当作更换身份；活动通话存在时仍禁止实际更换供应商身份。只读管理员不会获得密钥表单和检测按钮。

## 资源未就绪说明

资源列表与聊天能力诊断说明具体资源编号、AppID是否匹配、是否允许使用、权益及停止确认、周期、官方用量是否过期、路由与双端安全窗口额度等原因。现有资源可在复核表单调整官方用量有效时间；300秒等有效时间仍由管理员按官方用量更新频率设置，不自动伪造最新官方消耗。

## 更新范围

PHP后台、页面、JS/CSS及说明文档，无SQL迁移、Go二进制或小程序变更。新增ASR预设保存在现有system_settings；权益确认元数据保存在现有JSON字段。同步文件后在后台保存并应用配置，测试站由新版启动器自动处理。

测试仅在独立workers-server运行，使用临时MySQL和合成凭据，覆盖真实数据库保存与失败回滚、权限/CSRF、资源和开关回显、合并表单以及手机/桌面浅色与暗黑布局。未连接宝塔、未操作服务器，也未实际调用微信识别或供应商通话。
