## 会话管理与真实链路
入口：测试站后台 → 聊天管理 → 会话测试。超级管理员可从管理员、演示客户、演示师傅中选择2～20人，创建双人或多人会话；无需短期入口。
选择会话后，端A和端B分别选择不同成员并点击“接入”。可只接入一端，在小程序管理员工作台切换到对应演示身份，进入消息页使用另一端。
- 文字、单图/相册、MP3语音、MP4视频使用与小程序相同的 ChatManager / ChatImages / ChatAV 状态机，进入真实Go上传、内容检查、审核、发布、播放、撤回链路。不会绕过图片预审、视频完整预审、ASR或微信媒体审核回调。
- 语音支持1～60秒、1MB内MP3；视频支持120秒、20MB内H264/AAC MP4。图片最多9张、单张8MB。处理失败可核验、重试或取消原操作，避免重复发送。
- 媒体待处理状态自动同步，审核通过后自动更新；断开、切换身份或会话失效时清空本端已显示的消息并停止采集。
- 能力缺项时保持不可用，展示实际状态。沿用聊天设置中的七牛公开空间/聊天目录、Python环境、Pillow/zxing-cpp、FFmpeg/FFprobe、微信ASR及回调配置，不新增一套供应商凭据。
- 小程序演示身份的文字及媒体审核使用本次实际登录管理员的微信绑定，不借用演示用户的占位身份；浏览器测试沿用后台已配置且实际登录过的小程序管理员绑定。不会伪造OpenID。缺少真实绑定时不可绕过审核。

## 真实音视频通话
浏览器使用官方声网Web SDK 4.22.2，与小程序使用Go签发的同一频道、Token及双端UID，采用H264。点击呼叫才加载SDK；接听后才申请麦克风/摄像头权限。需HTTPS及浏览器权限。
联调通话强制使用声网资源池，实际消耗现有额度；资源池、供应商控制凭据、额度或停止核验缺失时拒绝呼叫。普通订单的通道策略保持原样。
复用已有呼叫、接听、拒绝、准备、双端就绪、心跳续权及挂断流程。切换身份、断开、离开页面和页面进入后台会停止本端采集并尝试挂断；授权期限到达也会停止。SDK离开不代替服务端停止证明，额度结算继续遵循既有规则。

## 隔离与清理
- 新授权仅在test环境使用，绑定真实超级管理员登录或小程序演示身份的原登录；会话授权最长5分钟，身份失效、角色改变或切换演示身份后立即失效。不能进入普通订单会话，普通登录也不能进入隔离会话。
- Go会话编号使用正常自增，虚拟身份及业务绑定分别使用独立字符串范围，避免污染正常会话自增值。测试聊天不写订单、不改用户登录身份、不发送自动订阅消息或短信。
- 删除会话/一键清空会立即移除列表并阻止继续访问。Go后台清理正文及媒体引用，通过已有对象账本删除云端文件；删除失败会保留账本重试，不宣称已删除。活动通话或处理中媒体先结束再清理。真实通话计费、停止核验凭据保留用于对账。
- 旧文字演练记录保留在折叠区；新消息全部进入真实聊天链路。

## 小程序会话审计修复
- 普通返回保留当前账号的消息与已核验成员资料，不重建会话；消息列表后台刷新资料，不因云端登录读取较慢而阻塞已有列表。身份、站点切换和权限收回仍清理相应内容。
- 打开会话优先恢复本会话，再刷新账号列表；聊天可用状态没有变化时不重复执行页面初始化。凭证被服务端明确拒绝时只刷新并重试一次，保留原消息编号。
- 输入文字后发送键替换右侧加号，键盘确认键发送；发送不强制收起键盘。原生导航栏高度不重复计入页面，键盘弹起时移除底部安全区重复留白。
- 语音按住录制、松开发送，上滑取消、滑回恢复；不足一秒不发送，退出页面或权限变化取消采集。图片、音视频仍走原上传、审核、发布和撤回链路。
- 长按菜单在消息气泡旁显示，位置受可视区约束；消息变更、离开页面或切换身份后不能继续执行旧菜单。图片单项回复和举报继续保留。
- 使用服务端确认的已读/未读计数，双人和多人均可查看；仅在已完成同步且实际停留在最新消息底部时确认已读。历史浏览不推进到尚未阅读的位置，连接异常不推断已读。
- 演示群显示已选身份名称；测试成员管理经专用接口添加、移除、退出，使用已有房间revision进行并发校验并推进Go权限版本，不调用真实订单群邀请。仅允许管理员和已登记演示身份，双人会话通过后台清理。
- 更多功能可分享当前账号订单，支持分页选取和发送确认；只含订单标题、公开编号，不含电话、地址。卡片以兼容文字附件保存，旧客户端仍能读取；打开仍经原订单详情权限校验。
- 更多功能保留语音/视频通话入口；服务缺项时明确提示检查资源、额度、私有端点及Go通话开关，不能通过显示入口绕过真实开通条件。已就绪时复用同一声网呼叫、接听和挂断链路。
- 本轮为2.7.3修补：需同步PHP/前端/浏览器bundle并重启Go，无新增数据库升级或云函数部署。正式站门禁保持独立。

## 微信录音交互与直传域名补修
- 录音交互参考腾讯云官方[TUIKit小程序MessageInput](https://github.com/TencentCloud/chat-uikit-wechat/blob/bc3db042856953e4f41d08270cb2ab47802c905b/components/TUIChat/components/MessageInput/index.js)的按住、上滑取消与松开发送流程，自行实现并继续使用原Go审核链路；不引入腾讯云IM SDK。
- 以RecorderManager的onStart作为录音开始依据；首次授权结束后若已松手，不会后台继续录音。中断、页面退出和账号切换取消录音。滑回按钮区域恢复发送，短于1秒不发送。
- 语音待发送项显示为本人消息气泡；上传、检查、待审核显示轻提示，失败用红色重试入口。长按可试听、重试或取消，后台仍核验原消息编号。已发表群消息和群成员列表显示已授权的人员名称。
- 输入发送键固定宽度，更多功能四列换行，避免原生button默认宽度挤压输入框或使工具栏溢出；补齐订单图标。
- 小程序继续直传七牛，服务器签发短期上传凭证并处理、审核、发布。当前测试站上传地址为 `https://up-z0.qiniup.com`，需在**微信公众平台 → 开发管理 → 开发设置 → 服务器域名 → uploadFile合法域名**添加。开发者工具随后执行**详情 → 域名信息 → 刷新**，重新编译；真机需关闭重开小程序以读取新配置。不关闭合法域名校验。
- 若后台七牛上传地址变更，微信后台必须允许对应实际域名；播放下载还需允许后台配置的七牛下载域名。前端明确区分域名未配置、网络中断和内容审核未完成。
- 测试环境凭证的通话能力改为读取实际Go运行配置，不再固定返回已开启；模块关闭时已认证的availability返回不可用、inbox返回空列表，写操作仍拒绝，避免404与轮询噪声。无图片时不再注册空的图片可见性观察器。
- 本轮仍为2.7.3修补，无新增数据库迁移或云函数变更；PHP和Go均需随main同步，重新编译小程序。七牛合法域名属于微信平台配置，仓库提交不会自动修改该配置。
