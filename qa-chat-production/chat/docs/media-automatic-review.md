# 聊天图片与视频策略（2.7.4）
图片主图无损优化优先，超过长边1600像素或8 MiB上限时缩放、重新编码；1 MiB仅用于选择传输方式；上传源文件仍限制8 MiB、2000万像素。缩略图为最长边600像素、JPEG质量90的预览图。
根据服务端主图实际字节数选择加载方式：不超过1 MiB直接显示主图；超过1 MiB先显示缩略图，进入查看页后由“查看原图（大小）”按钮明确触发主图下载。已查看过的主图优先复用缓存。已缓存主图可在云端过期后继续使用；无本机主图时回退永久缩略图并标记。保存按钮保存当前显示文件，支持本机缓存路径。
图片主图默认保留60天，期限由后台图片保存策略设置；缩略图永久保留。到期清理仅删除主图，不删除消息、尺寸信息与缩略图；普通用户访问仍受会话权限、撤回状态约束。后台历史查询保留图片记录，主图过期后显示缩略图。
视频保持客户端有损压缩、服务端重新封装；默认60天清理主文件，封面与抽帧保留。文字及语音默认永久保存。
图片与视频正常内容检测通过自动发布；风险内容进入复核。正式对象必须带扩展名，不保留无后缀兼容。
2.7.4数据库升级仅将未经管理员修改的旧图片默认策略改为60天，通过后台应用队列更新已有正式消息；自定义策略保留。部署需要Go、PHP、helpers、assets、小程序与数据库升级一起更新。
